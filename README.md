# ✋ Hand Gesture Media Controller

A Computer Vision project that allows users to control their Mac using hand gestures.

## 🚀 Features

- 🔊 Volume Control using Thumb & Index Finger
- 👍 Thumbs Up → Maximum Volume
- 👎 Thumbs Down → Mute
- ▶️ Play / Pause Music
- ⏭️ Next Track
- ⏮️ Previous Track
- 📊 Animated Volume Bar
- 🎨 Professional UI
- ⚡ Real-time Hand Tracking

## 🛠️ Tech Stack

- Python
- OpenCV
- MediaPipe
- NumPy
- AppleScript
